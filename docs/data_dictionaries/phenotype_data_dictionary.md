# Variant Phenotype Data Dictionary

**Project:** Pharmacogenomics Machine Learning

## Dataset Summary
**Dataset:** var_pheno_ann.tsv\
**File Type:** TSV\
**Description:**  Contains associations in which the variant affects a phenotype, with or without drug information.\
**Source:** ClinPGx\
**Records:** 14,490 entries\
**Features:** 25 columns\
**License:** (Reference the DATA_LICENSE.md from ClinPGx.)

| Column | Data Type | Description | Example | Missing Values | Notes |
|:-------|:---------:|:-----------:|:-------:|:--------------:|:------|
| Variant Annotation ID | integer | Unique ID number for each variant/drug annotation | 1449169911 | None | No repetitions |
| Variant/Haplotypes | text | dbSNP rsID or haplotype(s) involved in the association | rs1045642 | None | In some cases, an association is based on a gene phenotype group. |
| Gene | categorical | HGNC symbol for the gene involved in the association | ABCB1 | Yes | Typically the variants will be within the gene boundaries, but occasionally this will not be true. |
| Drug(s) | text | The drug(s) involved in the association | clopidogrel | Yes | If there is more than one drug listed, the association may apply to each drug individually or the combination of the drugs together. |
| PMID | integer | PubMed identifier for the article supporting the annotation | 28692418 | None | Includes repetition |
| Phenotype Category | categorical | Type of phenotype | Toxicity | Yes | Options are "efficacy", "toxicity", "dosage", "metabolism/PK", "PD", "other" |
| Significance | boolean | The significance of the association as stated by the author | yes | None | options are [yes, no, not stated] |
| Notes | text | Free text field for notes added by the curator | Please note that alleles have been complemented to the positive strand. | Yes | Includes repetition |
| Sentence | long text | The structured annotation sentence generated by the variant annotation tool based on the information entered by the curator | Allele A is associated with increased risk of Malignant Hyperthermia as compared to allele G. | None | Includes repetition |
| Alleles | text | The basis for comparison in the annotation | A | None | In this field, there may be a variant, one or more haplotypes grouped together, one or more genotypes grouped together or one or more diplotypes grouped together. |
| Specialty Population | categorical | Any special populations this annotation is relevant to | Pediatric | Yes | "Pediatric" is the only value in this column |
| Metabolizer types | ordinal categorical | This field contains the gene phenotype group, if applicable | poor metabolizer | Yes | If the association is based on a gene phenotype group, or if the association is based on individual genotypes that were combined into a gene phenotype group. |
| isPlural | boolean |  This field maintains grammar in the sentence | Is | None | Options are "is" and "are". |
| Is/Is Not associated | boolean | This field indicates whether or not an association was found | Associated with | None | Options are "associated with" or "not associated with" |
| Direction of effect | boolean | This field is a descriptor of the "Side effect/efficacy/other" field | increased | Yes | Options are "increased" or "decreased" |
| Side effect/efficacy/other | categorical | This field describes the "Phenotype" of the association | risk of | Yes | Options are "likelihood of", "risk of", "severity of" or "age at onset of". |
| Phenotype | categorical | This field is the resulting phenotype of the association | Side Effect:Drug Toxicity | Yes | This field can be free text or an existing term in ClinPGx; it is not standardized |
| Multiple phenotypes And/or | boolean |  If there is more than one entry in the "Phenotype" field, this field specifies if the phenotypes should be separated by "and" or "or" | and | Yes | Options are "and" or "or". |
| When treated with/exposed to/when assayed with | categorical | This field contains words that connect the first part of the sentence with the next part | when treated with | Yes | There are many options including, but not limited to, "when treated with", "when exposed to" or "when assayed with". |
| Multiple drugs And/or | boolean | If there is more than one drug in the "Drug(s)" field, "or" designates that the association applies to each drug individually, or "and" designates the association applies to the combination of the drugs together | and | Yes | Options are "and" or "or". |
| Population types | categorical | This field indicates the type of population in which the association was studied | in people with | Yes | The studied population can be further described in the "Population Phenotypes or diseases" field, in which case the "Population types" field will in with the word "with", such as "in children with" |
| Population Phenotypes or diseases | categorical | This field further describes the studied population entered in the "Population types" field by indicating if the population has a particular disease or phenotype | Disease:Breast Neoplasms | Yes | This column is part of the structured sentence in the "Sentence" field. |
| Multiple phenotypes or diseases And/or | boolean | If there is more than one entry in the "Population Phenotypes or diseases" field, this field specifies if the phenotypes should be separated by "and" or "or" | and | Yes | Options are "and" or "or". |
| Comparison Allele(s) or Genotype(s) | text | This field indicates if the study authors directly compared the allele(s) or genotype(s) in the "Variant/Haplotypes" field against other allele(s)/haplotype(s)/genotype(s) | G | Yes | This column is part of the structured sentence in the "Sentence" field. |
| Comparison Metabolizer types | ordinal categorical | This field indicates if the study authors directly compared the gene phenotype group in the "Metabolizer types" field against other gene phenotype groups | example | Yes | This column is part of the structured sentence in the "Sentence" field. |
