# Variant Drug Annotations Data Dictionary

**Project:** Pharmacogenomics Machine Learning

## Dataset Summary
**Dataset:** var_drug_ann.tsv\
**File Type:** TSV\
**Description:** This file contains associations in which the variant affects a drug dose, response, metabolism, etc.\
**Source:** ClinPGx\
**Records:** 12,975 entries\
**Features:** 21 columns\
**License:** (Reference the DATA_LICENSE.md from ClinPGx.)

---

| Column | Data Type | Description | Example | Missing Values | Notes |
|:-------|:---------:|:-----------:|:-------:|:--------------:|:------|
| Variant Annotation ID | integer | Unique ID number for each variant/drug annotation | 1448257202 | None | No repetitions |
| Variant/Haplotypes | text | dbSNP rsID or haplotype(s) involved in the association | rs1045642 | None | In some cases, an association is based on a gene phenotype group such as "poor metabolizers" or "intermediate activity". In these cases, the gene phenotype is found in this field. |
| Gene | categorical | HGNC symbol for the gene involved in the association | ABCB1 | Yes | Typically the variants will be within the gene boundaries, but occasionally this will not be true. |
| Drug(s) | text | The drug(s) involved in the association | warfarin | None | If there is more than one drug listed, the association may apply to each drug individually or the combination of the drugs together |
| PMID | integer | PubMed identifier for the article supporting the annotation | 21398039 | None | Includes repetition |
| Phenotype Category | categorical | Pharmacogenomic phenotype category | Efficacy | Yes | Options are "efficacy", "toxicity", "dosage", "metabolism/PK", "PD", "other". |
| Significance | categorical | The significance of the association as stated by the author | yes | No | options are [yes, no, not stated] |
| Notes | text | Free text field for notes added by the curator | Please note that alleles have been complemented to the positive strand | Yes | Includes repetition |
| Sentence | long text | The structured annotation sentence generated by the variant annotation tool based on the information entered by the curator | Allele C is not associated with response to corticosteroids in people with Asthma as compared to allele T. | None | Includes repetition |
| Alleles | text | The basis for comparison in the annotation | A | Yes | In this field, there may be a variant, one or more haplotypes grouped together, one or more genotypes grouped together or one or more diplotypes grouped together. |
| Specialty Population | categorical | Any special populations this annotation is relevant to | Pediatric | Yes | "Pediatric" is the only value in this column |
| Metabolizer types | ordinal categorical | This field contains the gene phenotype group, if applicable | poor metabolizer | Yes | If the association is based on a gene phenotype group, or if the association is based on individual genotypes that were combined into a gene phenotype group. |
| isPlural | boolean | This field maintains grammar in the sentence | Is | None | This columns is part of the structured sentence in the "Sentence" field |
| Is/Is Not associated | boolean / text | This field indicates whether or not an association was found | Associated with | None | This columns is part of the structured sentence in the "Sentence" field |
| Direction of effect | categorical | This field is a descriptor of the "PD/PK terms" field | increased | Yes | This columns is part of the structured sentence in the "Sentence" field |
| PD/PK terms | categorical | This field contains the pharmacodynamic or pharmacokinetic phenotype that was measured in the association | response to | Yes | This field also serves to connect the variant and drug together in the standardized sentence. |
| Multiple drugs And/or | boolean |  If there is more than one drug in the "Drug(s)" field, "or" designates that the association applies to each drug individually, or "and" designates the association applies to the combination of the drugs together | or | Yes | Options are "and" or "or" |
| Population types | categorical | This field indicates the type of population in which the association was studied | in people with | Yes | The studied population can be further described in the "Population Phenotypes or diseases" field |
| Population Phenotypes or diseases | categorical | This field further describes the studied population entered in the "Population types" field by indicating if the population has a particular disease or phenotype | Disease:Kidney Transplantation | Yes | If this field is filled in, the "Population types" field will end with the word "with" |
| Multiple phenotypes or diseases And/or | boolean | If there is more than one entry in the "Population Phenotypes or diseases" field, this field specifies if the phenotypes should be separated by "and" or "or" | and | Yes | Options are "and" or "or". |
| Comparison Allele(s) or Genotype(s) | text | This field indicates if the study authors directly compared the allele(s) or genotype(s) in the "Variant/Haplotypes" field against other allele(s)/haplotype(s)/genotype(s) | G | Yes | In this field, it seems that there may be a variant, one or more haplotypes grouped together, one or more genotypes grouped together or one or more diplotypes grouped together. |
| Comparison Metabolizer types | ordinal categorical | If there is more than one entry in the "Population Phenotypes or diseases" field, this field specifies if the phenotypes should be separated by "and" or "or" | normal metabolizer | Yes | Options are "and" or "or". |

## Data Quality Notes
- PD/PK terminology may become an engineered feature.
- PMID and evidence sentences are documentation fields rather than predictive features.
- Drug names should be standardized before merging datasets.
